# 日序｜我的網頁、交通同資訊站

首頁先處理 Task／行程。資訊站 →「資訊設定」有三個獨立開關：刊物、公開新聞、交通路況；每個帳戶初始全部關閉。啟用刊物後首頁最多只顯示「刊物 · N 期未讀」，零期不顯示。路況只在啟用後載入，新聞及刊物全文只在資訊站打開。

- **我的網頁**：五個現成公開捷徑（香港出行易、即時隧道費、香港天文台、Google Calendar、社署 CCSV）。個人收藏另列；只需網址，可以改名。首頁顯示最多六個私人捷徑，「管理收藏」可查看、移除或重新儲存。無讀取瀏覽器書籤、無抓取網站或 favicon。
- **交通**：`/briefing/traffic` 列運輸署有行車時間顯示器嘅起點、行駛方向、目的地、平均分鐘、狀況及量度時間。首頁最多三段，優先封閉／擠塞；不把沒有讀數或十分鐘以上資料當暢順。頁面可搜尋道路及目的地；特別交通消息分開，已解除事故不會以生效事故重列。
- **收費**：按香港當刻、車種（私家車或電單車）、已生效嘅運輸署分時及固定 CSV，以及 1823 公眾假期表計算。三條過海隧道、大欖及 CSV 有覆蓋嘅固定收費；不重複顯示備用收費點。超出時段、缺資料或假期不明不猜金額，並提供「香港出行易」官方查詢。不是收費亭實報、所有收費道路清單或帳戶扣款。停留本頁每分鐘查，背景分頁不輪詢。
- **資訊站**：美股／港股、指數圖（按用家要求先讀 TradingView）、香港新聞、手機／平板、居家護理市場。讀 RSS/Atom 的原文標題、刊登日期及連結；來源故障同「無相關新聞」分開。沒有政府新聞公報、新聞推送或付費 AI。美港市場速讀是來源精選，唔係投資建議或原訂閱研究報告。
- **私人刊物**：「醫療期刊」及「美股晚報」共用刊物庫，按出刊日排序。可按月份、分類、未讀／收藏或標題、全文搜尋；搜尋結果連去相關段落。打開內文並成功顯示後才記錄已讀；收藏係另一項獨立操作。開啟功能唔會自動取得其他人嘅刊物授權。詳見[接收及驗收](publications.md)。
- **稍後睇**：新聞可一撳收入自己嘅收藏，不會新增 Task。私人網址獨立保存，唔會進入共享筆記、家庭或其他用戶嘅收藏。資料庫 RLS 只認當前帳戶；移除只封存，重試不會重複。

公開資料：[行車時間顯示器及規格](https://data.gov.hk/tc-data/dataset/hk-td-sm_8-journey-time-indicators-v2)、[特別交通消息](https://data.gov.hk/tc-data/dataset/hk-td-tis_19-special-traffic-news-v2)、[官方收費 CSV](https://data.gov.hk/tc-data/dataset/hk-td-tis_15-road-network-v2)、[香港出行易分時收費](https://www.hkemobility.gov.hk/tc/toll-rate/)、[1823 公眾假期](https://www.1823.gov.hk/common/ical/tc.json)。
