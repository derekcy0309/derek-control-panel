# 日序 Dayline · 今日總覽

- **而家做**：你手排嘅 Today 次序優先；冇手排先按 Priority 建議。第一步同開工導航共用真正步驟／已儲存 checkpoint；「開始呢件事」唔會自行完成或交派任務。第二、三項喺「跟住做」，「自己排今日」可直接改次序。
- **加 Task**：打名稱、按 Enter；原有草稿、Tags、負責人、工作日、日期及重試仍然用同一個表單。「任務工具、提醒及篩選」保留專注計時、安靜模式、等回覆同完整任務清單。上方選單仍可進入原有各頁。
- **行程及限期**：今日起三個香港日期，顯示星期幾，分開行程時間同限期；另列三日以外本人下一個學校限期。已選 iCloud 行程唯讀，返 iPhone 改；唔會另建 Task。同一個跨日行程只展示一次並保留時間範圍，不會合併同名但不同時間嘅行程。「更新」保留 Apple 獨立重讀及失敗提示；「建議停止工作時間」仍可改預留時間。
- **香港天氣**：香港天文台總部實測、未來三日預報及生效警告；手機可展開。警告來源不明時顯示「暫未能確認」，唔代表冇警告。有重大天氣安排請同時留意[香港天文台](https://www.hko.gov.hk/tc/)。新增唯讀 `GET /api/weather/hong-kong`，只取三個固定公開 feed，不接收地點、不傳用戶身份；只有公共天氣資料可共用短暫 cache。
- **版面同入口**：手機先見開工及跟住兩件，之後先見維港插畫及天氣；日曆可以按日期睇行程及限期。交通已搬到獨立「交通」頁，首頁唔再載入路況或隧道收費。資訊站可獨立打開閱讀，已啟用刊物嘅首頁只保留未讀提示。
- **全站導航**：登入後所有一般頁面共用同一套日序頂欄、每週配色及主要導航，入入面唔會換返舊側欄。「更多功能」保留家庭、個人財務、收集箱、設定及其他入口；管理員入口依舊只有管理員先見到。獨立 Agent 登入及離線提示維持分開。
- **外觀**：每星期一香港時間開始新配色，暖杏、霧藍、薄荷、淡紫輪換；已有夜班深色設定會保留。首頁名稱及 PWA 名稱更新，登入、舊網址同資料不變。

無新增環境變數、付費服務或 database migration；無修改 Grok、bot scope、授權或其他人用戶資料。私人日曆 API 維持 authenticated + no-store；額外學校查詢使用登入者 client、明確 owner 條件及一筆上限。要回復只需回到上一個 app deployment，毋須修改資料庫。
