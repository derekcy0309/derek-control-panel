# 日序 Dayline · 頂欄及更多功能

登入後，各個一般頁面共用同一個頂欄。預設捷徑為「今日總覽、我的任務、日曆、資訊站、交通」。頂欄只放你想快速打開的頁面；其他入口仍在「更多功能」。

## 自訂捷徑

打開右上角「更多功能」→「自訂頂欄捷徑」，揀你常用的功能和顯示次序，然後儲存。最多五個。由現有可用頁面揀，例如開工導航、子女及學校、私人筆記或個人財務；不能輸入任意網址。可以恢復預設。頂欄的「日序」標誌永遠返今日總覽。

捷徑沿用帳戶已有的 `user_settings.pinned_pages`，同一帳戶登入手機與電腦會收到同一套次序。不影響其他帳戶，也不更改權限。未有自訂的帳戶繼續顯示預設捷徑。

頂欄透過自己的私用摘要讀取帳戶身份、外觀及捷徑，不需要把任務、財務或其他工作區資料重讀一次。各頁仍按原來來源讀取自己的內容。

## 其他入口

- 「更多功能」仍有每日使用、計劃與跟進、協作與檢視、家庭、個人、系統設定分組。只向管理員顯示「帳戶活動」。
- 「快速收集」把新資料放入收集箱；「加 Task」沿用同一個任務表單。兩者沒有合併成一個資料來源。
- 「交辦及分享」由同一個入口打開。Request Duty、每週檢視及同步專注仍然各自運作。
- 交通是獨立頁面；將交通設為捷徑也只加入連結，不會在首頁載入交通、收費或顯示摘要。
- 舊網址、各模組和資料不會因改頂欄而刪除。
