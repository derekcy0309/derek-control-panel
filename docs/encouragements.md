# 雙語鼓勵語及顯示規則

系統使用 86 句經 Derek 確認的候選語錄：原有100句中精選50句，加上36句 Business 語錄。資料集中在 lib/encouragements.ts，每筆必須包含：

- 英文原句
- 香港繁體中文介面譯文（不宣稱是官方譯本）
- 英文及中文人物名稱
- 演說／作品／年份
- 可核實來源網址
- 主題及語氣強度

無法核實人物或來源的網絡語錄不可加入。舊有「唔好用今日嘅能量，批判整個人生嘅進度」屬系統原創文案，不再顯示，亦不可歸入任何名人名下。

## 輪替

選取使用頁面路徑及香港日期產生穩定結果，同時在瀏覽器保存最近12個語錄 ID，避免短期重複。20格主題序列的比例為：

- 溫和支持：35%
- 開始行動：30%
- 事業思維：20%
- 堅持向前：15%

這是整體顯示比例，不是醫療判斷。系統目前不會根據 depression、診斷或健康資料自動推斷使用者狀態。

## 權限

鼓勵卡是否顯示仍由既有 server-side Admin 設定控制：

- derekcy0309@gmail.com 預設顯示。
- 其他帳戶預設隱藏。
- 只有啟用中的管理員可於 /admin/accounts 更改個別帳戶。
- 設定保存於 Supabase Auth app_metadata.show_encouragement，一般使用者不能自行修改。

## 視覺

鼓勵卡位於每頁內容末端，列印時隱藏。卡內同時顯示中英文、作者、年份／場合及來源連結。右側插圖 public/illustrations/small-steps-sunrise.webp 由 image generation 產生，沒有文字、人物或名人肖像，只用作「小步前進」的視覺提示。
