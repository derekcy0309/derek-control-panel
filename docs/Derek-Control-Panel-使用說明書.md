# Derek Control Panel 使用說明書

> 適用版本：2026.07 production
> 對象：Derek、Suki 及 Amigo

這不是一個要求你做更多事的系統。它的作用是把「下一步是甚麼」變得清楚，讓工作中斷後容易重新開始，並讓 Derek、Suki 與 Amigo 可以安心交接。這是個人工作系統，不是營運或 CRM 系統。

## 先記住三個原則

1. 先寫下一步，再開始。任務可以很大，但下一步應小到能立刻開始。
2. 系統只會建議，不會自行完成、延期、交接或加入行事曆。
3. 私人資料預設私人；分享、交接和資源附件都要明確確認。

## 1. 第一次登入後：用 3 分鐘設定今日容量

到「設定」選擇自己的支援模式、Focus 計時長度、進行中上限（WIP）及預設範圍。這些設定只影響自己的建議，不會改動對方的工作。

| 你想處理的事 | 到哪裡 | 最小做法 |
|---|---|---|
| 今日有多少精神 | Today 首頁 | 選擇能量、可用分鐘和工作模式。 |
| 今日只想做最低限度 | Today 或設定 | 開啟 Gentle／低容量模式，系統會把今天收窄。 |
| 想減少同時進行的事 | 設定 | 填入適合自己的 WIP 上限。 |
| 想改計時習慣 | 設定 | 選擇 15、25 或 45 分鐘 Focus。 |

不確定怎樣填也沒關係。先選一個較保守的可用分鐘，之後可隨時修改；保留 buffer 比把時間表排滿更有用。

## 2. 每日最簡單流程

1. 開啟 Today，填寫今日能量、可用時間和工作模式。
2. 看「現在做」的一項建議；如不合適，按「換一件」、「太難」或「拆細一點」。
3. 確認後才加入 Today。系統不會未經同意改動任務。
4. 開始前確認任務有「下一步」；例如「打開表格，列出尚欠資料」。
5. 進入 Focus Mode，完成一節後寫下 checkpoint，再決定繼續、暫停或交接。

### 今天只做很少也可以

在低能量、Gentle 或 minimum-step 模式，Today 會顯示一項核心最低任務，另外最多兩項很簡單的選項。完成核心任務後，畫面會清楚表示今日核心責任已完成。

你可以選擇「今日休息」、「改做更簡單」、「只完成第一步」、「請 Derek／Suki 接手」或延至指定日期。選擇休息不會扣分、不會破壞連續紀錄，也不會把所有工作自動推到明天。

## 3. 新增任務：只需三項基本資料

在 Tasks、Today 的快速新增，或工作／家庭／個人模組按新增。最少只需填「要做甚麼」、「何時完成」及「負責人」。下一步、預計時間、能量、完成定義及重複設定都可稍後在詳情補充。

若任務需要另一人處理，選擇 Derek、Suki 或 Amigo 中已存在及已連接的帳戶。系統不會自行建立使用者。

1. 填寫交接 notes，說清楚已做到哪裡、對方第一步及有甚麼要等。
2. 儲存後，任務會送給對方接受；未接受前不會假裝已經交妥。
3. 對方在交辦中心或任務內按「接受跟進」。
4. 任務仍保留完整紀錄；交出者和跟進者都可查看進度。

如果不需要交接，保持「由我跟進」即可。這不會分享任務給對方。

## 4. 交接不是結束：怎樣把工作來回傳遞

打開已交接任務，會見到「現在由誰跟進」及跟進者選擇。每一段交接都必須留下 notes、下一步、日期時間和作者，令後手不用重新猜。

| 情況 | 現在跟進者應做甚麼 | 結果 |
|---|---|---|
| 已完成自己的一步，但要等結果 | 更新進度，填寫下一步和預計再跟進日期 | 工作保持連續，不會被錯當完成。 |
| 已完成自己的一步，仍由自己繼續 | 選擇「完成今步，我繼續跟進」 | 保留同一工作及所有 notes。 |
| 要交回上一手 | 選擇「交回上一手繼續跟進」 | 上一手可立即接續，紀錄完整保留。 |
| 全部已完成 | 選擇「完全完成工作」 | 工作正式完成；過往交接仍可查閱。 |
| 需要改由另一人做 | 按「由 Derek／Suki 跟進」並寫交接 notes | 對方接受後成為目前跟進者。 |

到「Sharing／交辦中心」的「工作進度」分頁，可回看所有曾經交接的工作、notes、進度百分比和時間線。這是追蹤工具，不是比較產量的地方。

## 5. 中斷後重新開始：Restart Checkpoint

每當暫停、離開 Focus、切換任務或工作結束，請花半分鐘寫 checkpoint：

- 我剛才完成了甚麼
- 現在做到哪裡
- 下一個最小步驟
- 下次要打開的文件、網址或頁面
- 阻塞原因（如有）

Focus Mode 會自動保存草稿；只有真正儲存成功才會顯示已安全儲存。如看到失敗提示，請保持頁面開啟、檢查網絡後再試。

下次打開同一任務，最上方會先顯示上次做到哪裡、立即下一步和可開啟的資源。按「從這裡繼續」即可回到原來的脈絡；舊 checkpoint 可在歷史中查看。

## 6. Focus Mode：只做眼前的一步

在任務內選擇 Focus，使用 15、25 或 45 分鐘計時。Focus 畫面只會顯示當前任務、下一步、完成定義、checkpoint 和該任務獲授權的資源，避免整個 backlog 干擾。

一節完成、部分完成或中斷都可以如實記錄。Focus History 是幫你恢復工作和改善估時的個人記錄，不會給對方作績效比較，也不會因為停止而自動完成任務。

## 7. Inbox：每次只處理一項

所有突然想到的事、手機快速收集、PWA 分享文字或網址，都可以先進 Inbox。不要在收集時逼自己立即分類。

開啟「Inbox Processing Mode」後，畫面一次只顯示一項，並顯示例如「3／12」的進度。每項可以選擇：

- 立即做
- 建立任務
- 加入 Project
- 加入 Waiting
- 交給 Derek／Suki
- 安排日期
- 保留作 Notes／Reference
- 略過，稍後再處理

建立任務時可以同時填寫下一步、預計時間、能量和 context。系統會保留原始 Inbox 內容和來源，並防止重複提交。剛處理錯時可使用「Undo 最近一次處理」。

## 8. Project、Waiting、依賴與日曆

### Project 與依賴

在 Project War Room 管理較大的結果、里程碑及任務依賴。用「blocked by／blocks」表明先後次序；系統會阻止循環依賴。被阻塞的任務不會被推薦為 Now task。前置工作完成後，系統只會提示可處理下一項，不會自動開始、完成或交接。

### Waiting

把任務狀態改為「等待別人」，填寫等待誰、等待甚麼和下一次跟進日期。Waiting 頁直接使用同一個 Work Queue，不需要再輸入另一份資料；等待工作不會佔用今日三項。

### Calendar

Calendar 用來放已確認的承諾，不是把整個 backlog 塞進行事曆。每日內部計劃、Quick Win 和 tentative schedule 不會同步。只有確認排程後，才可按 Personal、Family 或 Work 目標同步至已連接的 Google Calendar。Derek 的 Personal／Family 必須以 `derekcy0309@gmail.com` 連接；Suki 的 Personal／Family 必須以 `love29suki@gmail.com` 連接。

## 9. 通知、每日電郵及安靜時段

到「設定」的「真正通知系統」，在裝置上主動允許通知，然後按自己需要開啟 Today 第一項、deadline、Waiting 跟進、handover、Focus 完成及每日收尾提醒。

每位使用者可獨立設定安靜時段、night-shift 和提前提醒時間。通知在鎖定畫面只使用一般文字，不會顯示任務標題、健康、家庭、兒童、金額或聯絡資料。

如已開啟每日到期電郵，系統只會寄出屬於該使用者、未來三日內需要處理的事項；沒有符合事項便不寄出。另一位使用者的私人內容不會包含在電郵內。

## 10. Body Double：一起開始，各自工作

到 Body Double，雙方各自選一項任務及 15、20、25 或 45 分鐘。按 Ready 後可同步開始，但每人都可暫停、完成或離開，不會中斷另一人。

結束前各自寫 checkpoint。任務名稱只有在本人明確選擇後才顯示給對方；否則對方只會見到「私人任務」。畫面不會顯示產量排名。

## 11. 手機快速收集、離線及資源包

手機可用頂部「快速收集」輸入文字、貼網址、加入相片／文件或使用 PWA 分享。內容會先進私人 Inbox，稍後才處理。可預設提示交給誰，但系統不會因而自動交辦或分享。

離線時可以安全排隊處理純文字 Inbox、checkpoint 和 Focus 暫停／完成。恢復網絡後系統會以帳戶和唯一識別碼同步；如伺服器已有較新版本，會要求重新確認而不會覆蓋。附件不會離線保存。

每個任務可建立 Resource Pack，加入網址、文件、聯絡人、電話、Email、Notes、SOP、Decision、Project 或 Waiting。資源必須逐項授權；把任務交接不代表私人附件自動分享。

## 12. 使用 ChatGPT 建議（完全由你確認）

任務內可使用「ChatGPT 最省力分析」。系統會先遮罩常見敏感識別資料，準備只包含該任務的 Prompt，然後複製並開啟 ChatGPT。

1. 檢查 Prompt；不要主動加入私人身份資料、完整地址、密碼或不必要的敏感內容。
2. 在自己的 ChatGPT 對話貼上並傳送。
3. 複製回覆，貼回 Derek Control Panel。
4. 先看建議預覽，再按確認套用。

即使確認，系統只會更新完成定義、下一步和預計時間；不會自行完成、延期、分享、交接或加入 Calendar。ChatGPT 不可用時，基本任務功能仍然照常可用。

## 13. 每週檢視與容量提示

到 Weekly Review，用低壓力的八步流程回顧：本週完成、仍在處理、阻塞、Waiting、下週三個結果、容量、是否需要重新分工，以及下週第一個最小行動。

容量提示只會指出已知估時是否接近或超過自己填寫的時間，並溫和建議可考慮延後、拆細或交接的低影響工作。它不會自行改動任何任務。

## 14. 私隱、分享與備份

個人與工作資料預設私人。家庭項目只有在雙方已接受家庭連結後才可共同可見；未處理 Inbox 永遠先保持私人。

分享單一項目時，選擇參考、指派或共同管理，再明確決定是否包括附件、留言、連結文件或子任務。敏感項目的附件和 linked documents 不會預設包括。

到設定的「你的資料備份及安全還原」可以匯出自己的 JSON 或常用 CSV。還原前必須預覽；系統只新增不存在的資料，不會覆蓋、刪除或重設目前資料，也不會以備份重建另一人的分享或交接權限。

## 常見問題

### 為甚麼看不到「由誰跟進」？

新增任務時先打開「建立後由誰跟進（可選）」。舊任務則打開任務後，在「現在由誰跟進」選擇由我、Derek 或 Suki 跟進。若剛更新頁面仍未見到，重新整理一次；系統不應再把控制項隱藏。

### 對方沒有收到我交出的任務？

確認你已填交接 notes，然後到 Sharing／交辦中心的「等待接受」查看狀態。交接在對方按接受前仍屬等待接受，不應假設已完成。

### 任務未完成，但目前這一步做完了，怎麼辦？

不要把整個任務結案。更新進度、寫下一步和下次跟進日期；選擇「完成今步，我繼續跟進」或「交回上一手繼續跟進」。

### 系統顯示容量過多，是否會自動延期？

不會。這只是提醒。你可以保留安排、拆細、自己延期，或用正式交接流程請對方接手。

### 我想今天完全不做，會怎樣？

選擇「今日休息」。不會有負面警告、不會影響連續紀錄，也不會自動把所有工作推到明天。

### 我看見 checkpoint 未儲存成功，怎樣做？

不要立即關閉頁面。先檢查網絡，等待或按重試，看到「已安全儲存」後才離開；若仍失敗，先把文字複製到安全地方再聯絡管理者。

## 一個溫和的預設習慣

每天只需：收集一件事、選一個下一步、完成或暫停一節 Focus，然後留下一句 checkpoint。其餘功能在需要時才打開。

系統的成功不是清空所有清單，而是令 Derek、Suki 和 Amigo 在下一次打開時，都知道最容易開始的一步是甚麼。
