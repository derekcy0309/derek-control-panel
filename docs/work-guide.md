# 開工導航使用指南

1. 在「今日總覽」輸入任務名稱，按 Enter 或「儲存任務」。預設由本人負責，不設限期；限期、標籤、其他負責人和工作日都可在「新增詳情」補充。可使用裝置鍵盤的原生聽寫功能。
2. 在「現在處理」直接開啟已連結且有權限的資源，或進入「開工導航」。已有手動次序就沿用；沒有手排才按優先級及限期建議。等候回覆、未接受或受阻的任務不會自動排到首位。
3. 中途暫停時，按「暫停並儲存位置」記下目前步驟。可先補充停在哪一頁或已核對甚麼。再次開啟同一項任務時，可按「從這一步繼續」。如果該步驟已更新，會優先顯示現行步驟。
4. 「完成這一步」只記錄進度。只有另行確認完成整項任務，或確認完成恆常工作的本期，才會更新相應狀態。記起其他事情，可以在導航原頁將備忘存入本人的收集箱，不會跳頁或另建任務。
5. 「行程及限期」分開列出香港時間的行程和限期。已選擇的 iCloud 行程為唯讀，如需修改請在 iPhone 編輯。來源未更新時會保留提示。「建議停止工作時間」按已讀取的下一個固定行程，扣除準備時間（預設 20 分鐘，可調整）。開工導航的提示不計工作 Google 日曆；資料不足時不估算可用時間。
6. 開始有困難時，可展開「我遇到困難」，選擇「步驟太大」、「欠缺資料」或「需要他人決定」。後兩項可編輯並複製書面草稿，系統不會替你發送。亦可按需要自行開啟共同專注。
7. 如果「現在處理」的首項任務有你在較早日期儲存、仍然適用的進度，可按「查看進度」到該任務的紀錄。不會另外推薦一項任務或更改手排次序。
8. 「每週檢視」預設只問三條問題：哪些做法值得繼續、哪些事項要等候或轉交，以及下次先做哪一步。如需查看完整流程，可轉至「詳細檢視（八步）」，已輸入的內容會保留。儲存草稿及確認完成均不會自動改動任務。

## 資料及權限

- 首頁和開工導航沿用相同的「今日」次序，均不會重排手動任務。選擇暫停時，系統透過現有權限儲存一筆獨立的進度記錄，不會改動任務狀態或其他專注模式草稿。
- 「工作草稿」只供本人閱讀，不會發送或分享，也不會錄音；私人備忘沿用收集箱的帳戶權限。存入備忘失敗時保留畫面文字，重試使用同一個操作識別。
- 日報只提供受登入保護的入口，不會附上私人文件連結。首頁和導航不會在 PWA 離線快取私人資料。
- 開工導航的停止提示每約五分鐘在前景更新；倒數在裝置上計算。提示不會更改日曆、發出新通知或改變任務次序。

## 驗證及回復

- `npm run test:work-guide`：起步、暫停後繼續、行程停止提示及「今日」排序。
- `node tests/browser/simple-mode.mjs`：以三個模擬帳戶在手機及電腦測試首頁、建立任務、排序、暫停、完成一步及完成整項任務。
- `node tests/api/work-guide.mjs`、`node tests/api/guide-inbox-memo.mjs`：以隔離環境核對實際端點的權限、隔離及重試。
- `node tests/api/weekly-review-draft.mjs`、`node tests/browser/weekly-review-short.mjs`：核對簡短與詳細檢視的資料相容、跨裝置草稿衝突和歷史唯讀。
- 這些改善毋須資料庫遷移或新增環境變數，亦未增加付費服務。如需回復，重新發布上一個已驗證的程式版本；已儲存的草稿、備忘及進度記錄會保留。
